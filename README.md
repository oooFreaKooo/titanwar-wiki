# Titan War Wiki

An unofficial fan wiki for Titan War heroes, skins, and gear. Not affiliated with or endorsed by the creators of Titan War.

GitHub Pages publishes the static site from `main` at [ooofreakooo.github.io/titanwar-wiki](https://ooofreakooo.github.io/titanwar-wiki/).

## Local development

```bash
yarn install
yarn dev
```

The dev server runs at http://localhost:3000/.
